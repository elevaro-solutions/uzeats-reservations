# Tablevera Documentation

Docusaurus site for Tablevera — developers, diners, restaurant staff, platform admins, architecture reference, and LLM agent context.

## Local development

From the repo root:

```bash
pnpm --filter @reservations/docs dev
```

Open http://localhost:3002

## Build

```bash
pnpm --filter @reservations/docs build
```

Static output is written to `apps/docs/build/` — deploy to any static host or serve with:

```bash
pnpm --filter @reservations/docs serve
```

## Structure

| Section | Audience |
|---|---|
| `docs/developers/` | Engineers — setup, API, env, deploy |
| `docs/diners/` | Guest-facing product help |
| `docs/staff/` | Restaurant partner dashboard |
| `docs/admins/` | Platform operators |
| `docs/architecture/` | System design |
| `docs/llm/` | AI coding agent context |

## Edit docs

Add or edit Markdown files under `docs/`. Sidebar is autogenerated from folder structure and `_category_.json` files.
