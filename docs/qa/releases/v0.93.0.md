## Release delta — Required

### Added

- [ ] **Superadmin paid period start:** Admin restaurant Package (detail + list Edit drawer) lets Super Admin set when paid billing starts. Future date = trial until first charge; today or earlier = current paid cycle start, renews one month later. Hidden for platform admin / account manager / impersonation. Partner Billing dates stay read-only
- [ ] **Fail-to-pay ladder:** On a disposable test restaurant, a past-due unpaid invoice advances grace (0–7, still listed) → overdue (day 8, finance charge ~1.5%, banner) → unlisted (day 14, diner listing hidden) → restricted (day 30, Hub limited to billing + existing reservations; no new covers) → terminated (day 60 only on the test venue: subscription cancelled, remaining upcoming bookings cancelled)
- [ ] **Restore and admin overrides:** Owner can pay to restore before terminate. Admin restaurant Invoices: pause, resume, extend grace, waive fees, force-restore (force-restore also pauses the ladder). Config: finance charge 150 bps default, declined-card fee $25 once per invoice

### Changed

- [ ] **Post-login preparing screen:** After diner web sign-in, “Preparing your table” (illustration, rotating messages, progress) replaces the blank white page and “Signed in” toast. Partner Hub shows “Preparing your restaurant”. Email-verification accounts skip it and go to verify-email
- [ ] **Switch plan right away:** Amount due today is the **full** new monthly price (unused current-plan time is not credited) and a new billing period starts now. Waiting until period end still costs $0 today
