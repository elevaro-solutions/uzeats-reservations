## Release delta — Required

### Partner Hub / Admin

- [ ] **Pin to sidebar:** pin a Settings / Grow / Insights (and admin Billing / Platform) hub card; it appears under the section and persists after refresh
- [ ] **No-show marking mode** (`manual_only` default): host/manager marks no-show → card-guarantee fee charges when configured; auto mode marks at slot end without charging
- [ ] **Follow-up emails:** no-show and completed visits send `booking_no_show` / `booking_completed` (or stub recorded) when SendGrid configured
- [ ] **Admin Engagement email** (`/admin/engagement`): send one-off diner outreach
- [ ] **Holiday catalog:** majors on by default; venue stays open until owner/manager **approves closing**; opt-out / auto-close per restaurant
- [ ] Holiday pickers show **Name (key)** (e.g. `Christmas Day (christmas_day)`)
- [ ] Closures & hours: **Require staff / manual approval before closing**; holiday dropdown fills date; **date schedule overrides** (close day or custom hours); pending holiday approvals list
- [ ] Setup guide includes steps for no-show defaults, holidays, follow-up templates, engagement email, partner holiday/no-show
- [ ] **Min / max party size (online)** on Restaurant profile; diner Guests picker follows bounds; **Large party** CTA when above max; API rejects out-of-range
- [ ] Discovery Guests picker allows parties up to **50**
- [ ] **Multi-cuisine** (up to 8) on restaurant profile; public listing shows cuisines
- [ ] Booking policies UI: grouped sections, tooltips, named holiday pickers (not raw keys only)
- [ ] New restaurant default slug is **location-based** (`name-city-state`)
