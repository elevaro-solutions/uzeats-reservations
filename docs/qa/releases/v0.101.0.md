## Release delta — Required

### Added

- [ ] **Default card:** Setup guide has a required “Add a default payment card” step; Billing Default payment method card adds/replaces the card (brand, last 4, expiry); saving retries open invoices
- [ ] **Failed charge alerts:** First failed auto-charge emails + in-app alerts the owner (reason, next retry, Replace card / Pay now); red banner on Billing and invoice detail; lost/stolen/expired card pauses retries
- [ ] **Admin Failed charges:** Admin → Billing list (restaurant, invoice, amount, reason, attempts, last attempt, next retry); admin billing alerts; new email templates editable
- [ ] **All restaurants:** Multi-restaurant owners/managers land on All restaurants (Overview, My restaurants, Reservations, Waitlist, Billing); picking a restaurant restores the menu; `?restaurant=` loads one
- [ ] **Pay all across restaurants:** One charge for every open invoice (selected restaurant or All restaurants); no double charge on a second click
- [ ] **Live floor Tables view:** Default tile view with chairs and Available / Reserved / Seated / Turning colors; drag to seat with fit outlines; next-booking line on free tiles
- [ ] **Table drawer:** Seat here / Complete / No-show / Refund deposit / Cancel; Upcoming today with Seat now; ⋯ Edit table opens `?editTable=` (hidden for hosts)
- [ ] **Online ordering:** Menu card with Live/Off switch and tracked UTM link; diner full-width Order online button; Off hides without deleting; hosts can’t toggle
- [ ] **Menu editor tools:** Search/filter, reorder, Popular star, Featured meter, Unsaved changes bar, leave warning, delete confirmations, save jumps to the invalid dish
- [ ] **Diner home stats:** Hero row with restaurants, cities, diners served, rating; zeros hidden

### Fixed

- [ ] **Declined card on add-ons:** SMS credits / 3D room open the card form instead of an error
- [ ] **Alert scoping:** Bell and Overview Unread alerts follow the selected restaurant; Mark all read only clears that restaurant
- [ ] **Admin package change:** No “No such subscription” error when the Stripe subscription is gone or from the other mode
