## Release delta — Required

### Added

- [ ] **Map clusters:** Overlapping restaurants collapse into a numbered bubble; clicking it glides and zooms in one level at a time until they separate, or lists the venues when they share the same spot; overlapping name labels hide but pins stay clickable

### Changed

- [ ] **Marker chips:** Each marker is one white chip (dot + name); hover deepens the shadow and pops the dot; the selected marker is a larger gold dot with a halo and its label hides while the card is open
- [ ] **Card polish:** Card fades in, tail lands just above the selected dot, time slots are lighter, photo arrows show on hover (always on touch), buttons have hover and keyboard focus states
- [ ] **Card stays inside the map:** Card and “restaurants here” list flip below the marker near the top edge, shift sideways near side edges, and the map pans so the card fits on a short map

### Fixed

- [ ] **Redeem inputs empty:** “Redeem points” inputs start empty with a “Min …” placeholder; typing 1432 does not produce 01432
- [ ] **Redeem validation:** Inline message matches the API (minimum, insufficient balance, deposit too small, capped amount); booking is blocked until the amount is valid
- [ ] **Map sync:** Marker labels and positions stay correct after filters change the result list
- [ ] **Short window:** On a short desktop window the map is not clipped and the filters scroll inside their panel
