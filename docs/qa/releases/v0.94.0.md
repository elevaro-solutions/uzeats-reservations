## Release delta — Required

### Added

- [ ] **Custom package duration:** Admin Plans & pricing Billing duration is number + Day / Week / Month / Year. A 14-day package labels price “per 14 days” and lists `/14 days` (not `/mo`). 2 weeks / 3 months / 1 year save and display the matching suffix
- [ ] **Manual invoice duration:** Create invoice duration defaults from the selected plan. 14-day plan → 14 Days; Annual on a 1-month plan locks to 12 months. List and invoice detail show “2 weeks” / “1 year”, not only “N mo”

### Changed

- [ ] **Assign/switch paid period:** Changing package extends the period by that package’s duration from the later of today or the current end — 14 days stays ~14 days, not +1 month. Package copy and price hint match the duration
- [ ] **Public pricing suffixes:** Diner `/pricing` shows `/ 14 days` (or the matching duration) and “billed every …” for custom packages. Monthly / Annual does not turn them into a yearly deal. 1-month packages still use `/ month` and annual. Partner Hub plan pickers match

### Fixed

- [ ] **Billing Pay now:** Owner Billing Pay now does not crash Stripe.js when the API returns a stub `pi_dev_*` secret. Card form appears when Stripe is configured; stub mode continues without an IntegrationError
