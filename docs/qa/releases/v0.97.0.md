## Release delta — Required

### Added

- [ ] **Visibility / activity:** Admin restaurants show Visible / Not visible and Active / Inactive. Not visible hides diner search and the public page. Inactive keeps the public page but disables Complete reservation and stays out of search. Existing venues stay visible and active until changed; trials stay public unless an admin hides them
- [ ] **App Store apps:** Diner web (downloads, footer, install bar, profile, reservations, for restaurants, pricing) and Partner Hub (sign-in, account menu, sidebar) link to live Tablevera / Tablevera Partner iPhone App Store pages (not “coming soon”)

### Changed

- [ ] **Admin invoice detail:** Amount hero, status once in the header, compact pay-link actions, two-column Details / Line items
- [ ] **Standing vs Listing:** More menu and bulk bar group Standing (Approve / Reject / Suspend) separately from Listing (Visible / Active). Listing actions only for approved restaurants
- [ ] **Suspend / Approve listing flags:** Suspend marks inactive + not visible and shows the closed booking card on the public page. Approve restores visible + active and the reservation form
- [ ] **Reason required:** Reject, Suspend, Not visible, Active, and Inactive ask for a reason (icons + tooltips on menu items)
- [ ] **Free Base billing:** Base / $0 plans hide paid billing cycle and duration; switching off Base starts the new plan now

### Fixed

- [ ] **Invoice due UTC:** Due dates show as UTC calendar days; grace copy does not use a past local date
- [ ] **Stripe terminal intents:** Invoice pay page and Billing Pay now / plan-switch do not mount Stripe Elements with a finished PaymentIntent

### Recommended

- [ ] **Local only:** Root `pnpm dev` no longer fails when web `predev` and widget `--watch` race on widget `dist/`
