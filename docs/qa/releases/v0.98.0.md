## Release delta — Required

### Changed

- [ ] **Branding folder:** Logo and gallery uploads on an existing restaurant use `restaurants/{id}/branding/` and still show on the public page.
- [ ] **Menu folder:** Dish photo uploads use `restaurants/{id}/menu/` and remain after save/reload.
- [ ] **Add restaurant drafts:** Photos uploaded before Create restaurant use `accounts/{userId}/drafts/` and stay on the new restaurant after create.
- [ ] **Avatar folder:** Diner profile photo uses `accounts/{userId}/avatar/` (web; mobile if this build is installed).
- [ ] **Review photos:** A booked diner can attach a review photo under `restaurants/{id}/reviews/`; a never-booked restaurant rejects the upload.
- [ ] **Platform media:** Admin Discovery images use `platform/discovery/`; Blog cover uses `platform/blog/`.
